# Manager Library — public page

Static public presentation site for Manager Library, a system for a small library to manage its book catalogue, members and loans, and to see which books are borrowed most.

This site does **not** talk to the API: it has no network calls, no forms and no login.

## How to open it

- Double-click `index.html`, or
- run `npx serve .` in this folder and open the printed address.

There is no build step and no external dependencies.
